# Omnia-Mundi

Omnia-Mundi — Trade Without Borders. Global distributed marketplace and trade platform.

## Этап 1 — главная страница (#2)

Новая статическая русскоязычная главная по утверждённому сбалансированному дизайну. Создана от `main`, без использования кода отвергнутого PR #1. Оба исходных TXT прочитаны полностью; они остаются без изменений. Детали приоритета требований: [docs/decisions/001-homepage-only.md](docs/decisions/001-homepage-only.md).

**Готово к проверке владельцем:** восемь фотографий Wikimedia Commons сохранены локально; авторы, источники, лицензии и обработка указаны в [ASSETS.md](ASSETS.md) и раскрываемом блоке «Источники изображений» на главной. Полные проверки пройдены на checkout. [Отчёт](docs/validation-2026-10-25.md), [скриншот 1440 px](docs/screenshots/homepage-1440.png), [скриншот 390 px](docs/screenshots/homepage-390.png). PR остаётся Draft.

### Локальный запуск

Никаких runtime-зависимостей, API, БД или секретов. В каталоге репозитория:

```sh
python3 -m http.server 3010 --bind 127.0.0.1
```

Откройте локальный адрес сервера в браузере. Скрипты не используют модули или fetch, но в управляемом Chromium этой среды открытие через `file://` запрещено политикой браузера; проверенный способ — локальный HTTP-сервер. Сервер предназначен только для локальной проверки, не для публикации.

### Проверки

В среде разработки установлены Python Playwright и Chromium (`/usr/bin/chromium`). В другой среде установите `playwright` в отдельное Python-окружение и Chromium; путь браузера указан в тесте. Сервер должен работать во время теста.

```sh
node --check app.js
node --check strings.ru.js
python3 tests/homepage.py
```

Проверяются ширины 320, 375, 390, 430, 768, 1024, 1440, 1920 и 2560 px, отсутствие горизонтального переполнения, фиксированные фото 118×118, автоматическое число колонок по доступной ширине на всех экранах, включая телефоны, локальный поиск, совместная фильтрация, пустая выдача, мобильная панель, сообщения будущих функций, Escape и возврат фокуса. По последнему решению владельца восемь товаров на 1440 px помещаются в один ряд; прежние требования четырёх колонок на компьютере и двух на телефоне отменены (см. docs/decisions/001-homepage-only.md). Полная проверка дополнительно проверяет загрузку фотографий, хеши и доступность атрибуции, отсутствие внешних запросов и ошибок JavaScript, неизменность логотипа/TXT и создаёт `docs/screenshots/homepage-1440.png` и `homepage-390.png`, `homepage-320.png`, `homepage-430.png` и `homepage-1920.png` и `homepage-2560.png`.

Поиск и категории работают только с демонстрационными товарами. Страна и цена — визуальные секции по заданию. Остальные кнопки показывают «Раздел находится в разработке». Нет авторизации, корзинной логики, платежей, финансов, внешних запросов страницы или сбора персональных данных. Сборка, переменные среды, миграции, тестовая БД и очистка данных не требуются.

### Файлы

- `index.html`: одна семантическая страница.
- `style.css`: компактный адаптивный интерфейс.
- `strings.ru.js`: русские строки и явно демонстрационные данные.
- `app.js`: локальная фильтрация, раскрытие панели, нейтральные сообщения.
- `assets/omnia-mundi-logo.svg`: точный логотип из main.
- `assets/products/*.jpg`: восемь оптимизированных локальных фотографий.
- `assets/products/sources.json`: авторы, лицензии, источники и хеши активов.
- `tests/homepage.py`: проверки реального Chromium.

Не сливать, не включать auto-merge и не публиковать без разрешения владельца. Переход к следующим этапам требует нового задания.

Максимальная ширина контейнера страницы — 1920 CSS px; на более широких окнах сайт центрируется с сохранением прежних внутренних полей.

## Issue #4 — типографика

Основной текст теперь 16 CSS px, второстепенные подписи и атрибуция 15 px, заголовок каталога 22 px, включая мобильные стили. [Отчёт и сравнение «до/после»](docs/validation-issue-4.md). Браузерный тест проверяет фактические размеры текста, обрезку/переполнение, раскрытые фильтры и атрибуцию, шапку и клавиатурное управление на всех девяти ширинах.
