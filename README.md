# Omnia-Mundi — Trade Without Borders

Три статические страницы на русском и английском: демонстрационный каталог (`index.html`), «Как это работает» (`how-it-works.html`) и «Зарабатывать с Omnia-Mundi» (`earn-with-omnia-mundi.html`). Единый переключатель RU | EN в шапке меняет язык страницы, метаданные, доступные подписи, каталог, источники изображений и диалоги.

## Локальный запуск

Windows:

```powershell
py -m http.server 3010 --bind 127.0.0.1
```

Linux/macOS и облачная среда:

```sh
python3 -m http.server 3010 --bind 127.0.0.1
```

Запускайте из корня репозитория. В локальном браузере:

```text
http://localhost:3010/index.html?lang=ru
http://localhost:3010/index.html?lang=en
http://localhost:3010/how-it-works.html?lang=ru
http://localhost:3010/how-it-works.html?lang=en
```

Это локальная разработка, сайт не публикуется. Сборка, Node.js для запуска, база данных, ключи и внешние сервисы не нужны. HTTP-сервер требуется в том числе для загрузки локального манифеста изображений; открытие через `file://` не является поддержанным способом запуска.

## Проверка языка

1. Откройте любую страницу и переключите RU → EN → RU мышью или клавиатурой (Tab, Enter/Space).
2. Перейдите в «Как это работает» / How it works и обратно в каталог, затем обновите страницу: язык сохраняется.
3. Попробуйте поиск «лампа» на RU и «lamp» на EN, выберите категорию и смените язык — выбранный ID категории сохранится. Поисковая строка не очищается, выдача пересчитывается по названиям текущего языка.
4. Откройте «Источники изображений» / Image sources и любую будущую кнопку: текст соответствует текущему языку, авторы и лицензии неизменны.

Приоритет: корректный `?lang=ru|en` → сохранённое `omnia.language` → RU. Для нового пользователя без параметра и сохранённого выбора используется RU; скрытой геолокации/автодетекции нет. Недоступность localStorage не ломает сайт: язык остаётся в URL и внутренних ссылках. Некорректный язык игнорируется. Исходный русский HTML остаётся доступным для чтения How It Works без JavaScript; рабочее переключение RU/EN и каталог требуют JavaScript.

## Архитектура локализации

- `locales/ru.js`, `locales/en.js`: одинаковые ключи для всей пользовательской информации, включая полный How It Works, заголовки вкладок, meta/ARIA, описания обработки фото.
- `i18n.js`: единое применение ключей, выбор/сохранение языка, URL/якоря, подписки на смену языка, проверка допустимой разметки.
- `site-data.js`: стабильные ID, категории, страны-коды, цены в целых евроцентах, метаданные нижней навигации. Переводы не являются товарными фактами.
- `navigation.js`: общие локализованные футер и диалоги.
- `app.js`: только каталог, локальный поиск/фильтры и чтение единственного `assets/products/sources.json` для атрибуции.
- HTML: статические RU-подписи для fallback с `data-i18n*` ключами. `app.js` подключается только на главной.

Прежний `strings.ru.js` заменён двумя совместимыми словарями и одним механизмом, не оставлен параллельным способом перевода. [Как добавить следующую страницу и ключи](docs/i18n.md). [Архитектурное решение](docs/decisions/003-i18n-ru-en.md).

## Тесты

В подготовленной облачной среде установлены Python Playwright, Chromium (`/usr/bin/chromium`) и Node.js для проверки синтаксиса. При работающем локальном сервере:

```sh
python3 tests/homepage.py
python3 tests/how_it_works.py
python3 tests/i18n.py
node --check i18n.js
node --check navigation.js
node --check app.js
node --check site-data.js
node --check locales/ru.js
node --check locales/en.js
git diff --check
```

В другой среде установите Playwright и укажите установленный Chromium в тестах. Все три набора используют реальный HTTP и браузер; никаких реальных заказов или денег. ## Сохранённые правила и ограничения

Белый фон, чёрный текст, прежняя гарнитура и логотип с прежним размером, max-width:1920px, типографика 16/15/22 px, фото 157×157 CSS px и автоматические колонки сохранены. Название, цена и страна центрированы. [Источники и лицензии](ASSETS.md); фото и исходный манифест не меняются ради переводов.

Демонстрационные товары — не реальные продажи. Вход, корзина и будущие разделы показывают локализованное сообщение о разработке. Регистрация, оплата, реальные заказы, выплаты, AI, API, БД и новые страницы не реализуются в этом этапе. Следующие этапы требуют отдельного задания. Только feature-ветки и Draft PR; не сливать, не включать auto-merge, не менять приватность и не публиковать без разрешения владельца.

## Issue #10 — Earn with Omnia-Mundi

Новая информационная страница подключена к существующему футеру через id earn. Открывайте `http://localhost:3010/earn-with-omnia-mundi.html?lang=ru` или `?lang=en`; язык сохраняется между всеми тремя страницами. Пять ролей, их требования/проверки, возможности и вознаграждения описаны по регламенту. Customer не шестая зарабатывающая роль. Кнопка заявки показывает только прежний локализованный диалог о разработке — нет реальных регистраций, заявок, выплат или обещаний дохода.

При работающем сервере дополнительно выполните `python3 tests/earn.py`. [Фактические результаты, финансовые проверки и настоящие скриншоты RU/EN](docs/validation-issue-10.md); [логи команд и exit codes](docs/test-results/issue-10/results.json).
