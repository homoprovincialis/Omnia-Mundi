# Итоговая проверка главной страницы — 25 октября 2026 года

## Источники и лицензии

По утверждённому владельцем решению из PR #3 использован Wikimedia Commons вместо Unsplash. Для каждого включённого файла прочитана страница источника и лицензионный блок, получены imageinfo/extmetadata, скачан оригинал с сохранением TLS-проверки; SHA-1 совпал с Commons. Шесть файлов — CC0 1.0, кошелёк Pixloom — CC BY-SA 4.0, наушники Evan-Amos — Public domain (PD-self). У термоса указан музейный кредит; отдельный фотограф на странице не назван, автор предмета не выдан за фотографа.

Сомнительный кандидат `Headphones (56330).jpg`, визуально совпадавший с Unsplash при ином авторстве, не использован. Подобран `Sony-MDR-CD580-Headphones.jpg` Evan-Amos. Остальные семь — из списка владельца. Предметы просмотрены; термос соответствует термосу, сумка — сумке. Обозначения изготовителей не ретушированы и не используются как оформление или заявление о партнёрстве.

Локальные JPEG 354×354 оптимизированы с сохранением пропорций и белыми полями; размер отображения строго 118×118 CSS px. Авторы, источники, лицензии, изменения и хеши сохранены в ASSETS.md, sources.json и доступны в блоке «Источники изображений» на главной. Производная фотография кошелька сохраняет CC BY-SA 4.0. Unsplash-активов в Git нет.

## Границы проверки

Прямое открытие `file://` заблокировано политикой управляемого Chromium и не объявляется проверенным. Страница проверена через локальный HTTP-сервер. Прямое чтение creativecommons.org вернуло 403; условия лицензий проверены на доступных страницах Commons и в их метаданных. Это не препятствует выполнению явно опубликованного там разрешения и атрибуции.

Это только статическая главная и демонстрационный каталог. Авторизация, корзина, оформление заказов, финансы, API, база данных и следующие этапы не реализованы по заданию. Проверка визуального соответствия владельцем ещё ожидается.
