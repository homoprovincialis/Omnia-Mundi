## Источники и лицензии

По утверждённому владельцем решению из PR #3 использован Wikimedia Commons вместо Unsplash. Шесть файлов — CC0 1.0, кошелёк Pixloom — CC BY-SA 4.0, наушники Evan-Amos — Public domain (PD-self). У термоса указан музейный кредит; отдельный фотограф на странице не назван, автор предмета не выдан за фотографа.

Сомнительный кандидат `Headphones (56330).jpg`, визуально совпадавший с Unsplash при ином авторстве, не использован. Подобран `Sony-MDR-CD580-Headphones.jpg` Evan-Amos. Остальные семь — из списка владельца. Предметы просмотрены; термос соответствует термосу, сумка — сумке. Обозначения изготовителей не ретушированы и не используются как оформление или заявление о партнёрстве.

Локальные JPEG 354×354 оптимизированы с сохранением пропорций и белыми полями; размер отображения строго 118×118 CSS px. Авторы, источники, лицензии, изменения и хеши сохранены в ASSETS.md, sources.json и доступны в блоке «Источники изображений» на главной. Производная фотография кошелька сохраняет CC BY-SA 4.0. Unsplash-активов в Git нет.

## Границы проверки

Прямое открытие `file://` заблокировано политикой управляемого Chromium и не объявляется проверенным. Страница проверена через локальный HTTP-сервер. Прямое чтение creativecommons.org вернуло 403; условия лицензий проверены на доступных страницах Commons и в их метаданных. Это не препятствует выполнению явно опубликованного там разрешения и атрибуции.

Это только статическая главная и демонстрационный каталог. Авторизация, корзина, оформление заказов, финансы, API, база данных и следующие этапы не реализованы по заданию. Проверка визуального соответствия владельцем ещё ожидается.

## Git

Ветка `feat/homepage-phase-1`, Draft PR #3. Main не менялась; auto-merge, слияние и публикация не выполнялись. Прежний блокер Unsplash устранён заменой источника, а не обходом его ограничений.


Обновление сетки выполнено по [новому решению владельца](https://github.com/homoprovincialis/Omnia-Mundi/pull/3#issuecomment-6397937448). В пользовательском коде изменены только ширина `.catalog` и автоматическое число столбцов `.products`; логотип, шапка, меню, фильтры, фотографии, тексты, атрибуция и футер сохранены.


Последнее [уточнение владельца](https://github.com/homoprovincialis/Omnia-Mundi/pull/3#issuecomment-6397996563) отменяет также фиксированное число колонок для телефона. Единственная правка пользовательского CSS в этой итерации — удаление `grid-template-columns:repeat(2,118px)` из мобильного media query. Теперь весь каталог использует общий автоматический алгоритм. Остальные стили и поведение не менялись; скриншоты 390/1440/1920 после повторной генерации совпадают с прежними побайтно, добавлены 320 и 430.


### Итог после ограничения контейнера 1920 px

По [последнему решению владельца](https://github.com/homoprovincialis/Omnia-Mundi/pull/3#issuecomment-6398083571) единственная правка пользовательского CSS — `max-width:1920px` вместо 1488 px у `.page`. Полный тест повторён на девяти ширинах, включая 1440/1920/2560 и 320/390 px. Проверена реальная ширина контейнера `min(ширина окна,1920)`, его центрирование (при 2560 px боковые внешние поля по 320 px), автоматические колонки, отсутствие переполнения и размеры фото. Финальные скриншоты 1440/1920/2560 и мобильные пересозданы; 1440 и мобильные остались побайтно прежними. Предыдущие записи о побайтовой неизменности 1920 px описывают предыдущую итерацию: в текущей этот скриншот изменился из-за увеличения контейнера.
