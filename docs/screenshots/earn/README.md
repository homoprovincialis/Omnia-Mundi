# Настоящие скриншоты Earn with Omnia-Mundi

Шесть полных PNG реально отрисованной страницы `earn-with-omnia-mundi.html`: RU/EN × 390/1440/1920 CSS px. Созданы `tests/earn.py` в Chromium через Playwright, без стоковых, синтетических или похожих сторонних изображений. Файлы не менялись после browser screenshot. Новых фото страница не содержит: только утверждённый SVG и информационный текст нашего сайта.

`captures.json` содержит точный локальный URL, выбранный язык, viewport, fullPage=true, scale factor, версию Chromium, время UTC и SHA-256 PNG/отрисованного HTML. [Фактический отчёт](../../validation-issue-10.md).
