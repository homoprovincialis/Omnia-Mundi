# Скриншоты главной страницы

Сформированы `tests/homepage.py` из текущего checkout через локальный HTTP-сервер в Chromium; ширины в CSS px, scale factor 1.

- `homepage-1440.png` — компьютер.
- `homepage-390.png` — телефон, полная высота страницы.

Включённая фотография кошелька: **Pixloom, «A men's wallet.jpg»**, [источник](https://commons.wikimedia.org/wiki/File:A_men%27s_wallet.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). В миниатюре: уменьшение, белые поля, JPEG-оптимизация и удаление EXIF; без ретуши. Производная фотография сохраняет CC BY-SA 4.0, в том числе при включении в эти скриншоты.
