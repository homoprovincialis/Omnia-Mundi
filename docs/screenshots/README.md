# Скриншоты главной страницы

Сформированы `tests/homepage.py` из текущего checkout через локальный HTTP-сервер в Chromium; ширины в CSS px, scale factor 1.

- `homepage-1440.png` — компьютер.
- `homepage-390.png` — телефон, полная высота страницы.
- `homepage-1920.png` — широкий экран.
- `homepage-2560.png` — окно шире максимума: контейнер 1920 px по центру.
- `homepage-320.png` — узкий телефон.
- `homepage-430.png` — широкий телефон.

Обновлены после решения владельца об автоматическом количестве товаров в строке: фиксированного количества колонок нет ни на одном экране. На 1440/1920 px восемь товаров в одном ряду; на 390 px естественно помещаются две колонки, на 430 px — три.

Включённая фотография кошелька: **Pixloom, «A men's wallet.jpg»**, [источник](https://commons.wikimedia.org/wiki/File:A_men%27s_wallet.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). В миниатюре: уменьшение, белые поля, JPEG-оптимизация и удаление EXIF; без ретуши. Производная фотография сохраняет CC BY-SA 4.0, в том числе при включении в эти скриншоты. Остальные фотографии и условия перечислены в [ASSETS.md](../../ASSETS.md). Это не заявление о передаче прав на логотип проекта или о поддержке сайта правообладателями.

После уточнения максимальной ширины скриншоты пересозданы: на 1920 px контейнер занимает всю ширину окна, на 2560 px ограничен 1920 px и центрирован. Остальные скриншоты не изменились побайтно.
