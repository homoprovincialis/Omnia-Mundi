# Issue #10 — отчёт проверки Earn with Omnia-Mundi

База: main `fa1bc9ff3cfa2ecbaab92976cb8f777fdbd9ac4e` после слияния владельцем PR #9. Ветка: `feat/earn-with-omnia-mundi`. Создана одна информационная страница на RU/EN; существующий пункт earn в футере стал настоящей ссылкой. Реальных регистраций, заявок, операций, выплат, AI, API и БД нет. Остальные будущие пункты сохраняют заглушку.

## Соответствие требованиям

| Требование | Страница/проверка |
| --- | --- |
| Ровно пять ролей | Пять `.earning-role` с заголовками Procurer, Manufacturer, Seller, Receiver, Moderator. Для каждой ровно пять видимых полей: работа, проверки, возможности, вознаграждение, будущая заявка |
| Procurer | Свои средства, подтверждение закупки/первой отправки, добровольные задачи; раннее возмещение после выполнения части и подтверждения оплаты отделено от 20% P после финального закрытия |
| Manufacturer | Цена передачи может включать доход и не равна обязательной себестоимости; консигнация без предварительного выкупа, добровольный ассортимент; 20% P только как единственный источник обычной сделки |
| Seller | Право распоряжаться, состояние, цена передачи; цена/доставка/20% P по правилам финализации, не отдельная доля одновременно с другими источниками |
| Receiver | Home/Warehouse/Store; помещение и допуски; самостоятельное финансирование Store; 20% P, депозит не прибыль и не автоматическое правило консигнации, SSC отдельно до P и не прибыль |
| Moderator | Человек, три специализации 5/5/10% =20% P; совмещение суммирует доли без удвоения; не обещана неутверждённая плата за помощь вне сделки |
| Customer и допуски | Покупатель не шестая зарабатывающая роль; несколько ролей в одном будущем аккаунте, независимые проверки; служебные права отдельно |
| Финансовый пример | Видимые семь строк: 20/20/5/5/10/20/20 =100% P; 200/200/50/50/100/200/200 центов =1000; P не конечная цена, Protection Fund не доход компании |
| Участие | Будущая регистрация → заявка → проверка/подготовка → допуск → добровольное выполнение. CTA только открывает локализованный существующий диалог, не меняет URL и не отправляет данные |

Основание бизнес-текстов: §01–06, §10–13, §16.9, §19, §24–29 утверждённого регламента. Специальные сроки, доходность, комиссии и консигнационные депозиты не придумывались.

### Покрытие браузерных проверок

- Существующие главная и How It Works: прежние тесты, две локали и девять ширин. Footer guard изменён только с 1 ссылки/15 кнопок на 2 ссылки/14 кнопок; прежние неоднозначные селекторы теперь явно выбирают How It Works. Проверки не отключались.
- Earn: **18 сочетаний** RU/EN × 320/375/390/430/768/1024/1440/1920/2560 CSS px. Вместе с прежними страницами — все три страницы в двух языках на девяти ширинах.
- Проверены title/meta/ARIA/html.lang/aria-pressed, отсутствие русских фраз в EN, размеры шрифтов 16/15/22, логотипа 150/160, контейнер 1920 с центрированием; нет переполнения/обрезки текста и таблицы, наложения шапки.
- Фактически прочитаны все пять полей каждой роли и значимые финансовые формулировки в обоих языках. Арифметика проверяется по **видимым** ячейкам, не по спрятанным числам.
- Клавиатурный CTA, видимый focus, Enter/Escape/возврат фокуса; CTA открывает только диалог и не меняет URL.
- Переключение RU↔EN на каждой ширине сохраняет ref/query/hash; прямые EN URL, reload, stored language/default RU, блокировка localStorage, русский fallback без JS.
- Главная → Earn, How It Works → Earn, Earn → главная/каталог/How It Works#income: реальные переходы, язык и целевой hash сохранены. Все остальные будущие кнопки также проверены.
- Нет внешних сетевых запросов, ошибок JavaScript и HTTP 404 в проверенных переходах. На Earn нет полей ввода, формы имеют только method=dialog; фиктивных статусов одобрения нет.

**Неуспешных проверок: 0. Непроведённых обязательных проверок: нет.** Реальные регистрации, заявки, платежи и выплаты не реализованы и не проверялись как действующие сервисы: они вне объёма. Английский текст требует визуального/редакционного утверждения владельцем, не объявляется юридически заверенным переводом.
