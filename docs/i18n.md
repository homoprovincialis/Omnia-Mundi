# Добавление страниц и переводов

Для всех новых страниц используется **один** механизм `OmniaI18n`. Не создавайте локальный переключатель, отдельный fallback-алгоритм или второй комплект бизнес-данных.

## Подключение

В `<head>` страницы, перед её прикладным кодом:

```html
<script defer src="site-data.js"></script>
<script defer src="locales/ru.js"></script>
<script defer src="locales/en.js"></script>
<script defer src="i18n.js"></script>
<script defer src="navigation.js"></script>
```

Общий футер/диалог сохраняют ID из существующих страниц. Каталожный `app.js` нужен **только** странице с каталогом. Две кнопки шапки имеют `data-language="ru"` / `data-language="en"`; общий модуль задаёт `aria-pressed`, локализованные ARIA и обработчики. Используйте существующие `.header-tools` и `.language-switcher`, не меняя логотип и геометрию каталога.

## Конкретный пример ключей

В `locales/ru.js` добавить строковые значения (внутри существующего объекта):

```js
"example.title": "Пример — Omnia-Mundi",
"example.description": "Описание будущей информационной страницы.",
"example.heading": "Пример",
"example.backLabel": "Вернуться в каталог"
```

В `locales/en.js` добавить **те же** ключи:

```js
"example.title": "Example — Omnia-Mundi",
"example.description": "Description of a future informational page.",
"example.heading": "Example",
"example.backLabel": "Return to catalog"
```

Разметка будущей страницы:

```html
<title data-i18n="example.title">Пример — Omnia-Mundi</title>
<meta name="description" content="Описание будущей информационной страницы."
      data-i18n-content="example.description">
<h1 data-i18n="example.heading">Пример</h1>
<a href="index.html#catalog" data-i18n="example.backLabel"
   data-i18n-aria-label="example.backLabel">Вернуться в каталог</a>
```

Это документационный пример, не дополнительный маршрут/страница. Существующие ключи `home.*` и `how.*` являются стабильными ID, их нумерованные суффиксы не следует перенумеровывать при вставке новых блоков; новые ключи предпочтительно называть по смыслу. При изменении одобренного текста обновляйте оба словаря, RU fallback HTML и тесты.

Поддерживаются:

- `data-i18n`: `textContent` для обычного текста; переменные не интерпретируются как HTML.
- `data-i18n-aria-label`, `data-i18n-placeholder`, `data-i18n-content`: доступные подписи, placeholder, мета-описание.
- `data-i18n-html`: фиксированная локальная строка с `<strong>` без атрибутов. Другие теги/атрибуты отклоняются; внешние/пользовательские строки сюда не передаются. Корневые ID, якоря и атрибуты элемента сохраняются.
- `OmniaI18n.t('catalog.count', {count: 8})`: именованные параметры; отсутствующий ключ/параметр вызывает ошибку вместо незаметного смешения языков.
- `OmniaI18n.subscribe(render)`: сразу выполняет render и повторяет после смены языка. Callback должен получать строки через `t`, сохранять стабильные ID выбранных фильтров и не пересоздавать сам переключатель (для сохранения фокуса).
- `OmniaI18n.link('how-it-works.html#income')`: ссылка с текущим языком. Обычные внутренние HTML-ссылки автоматически обновляются; внешние лицензионные ссылки и внутристранничные `#якоря` не переписываются.

`document.title` обновляется через ключ на `<title>`, мета-описание через `data-i18n-content`, `html.lang` — общим модулем. В новую страницу нельзя добавлять видимую строку или ARIA только на одном языке.

## Язык и сохранение

Валидный URL `?lang=ru|en` имеет приоритет над `localStorage['omnia.language']`; затем используется RU. Для новых пользователей RU, без определения страны или языка браузера. При смене сохраняются остальные query-параметры и hash текущего URL; HTML-ссылки между страницами получают язык. Reload восстанавливает выбор из URL; bare URL может использовать сохранённое предпочтение. Чтение и запись localStorage обёрнуты в try/catch: без хранилища достаточно URL. Неверный код языка не применяется. Выбор не запускает внешний переводчик и не передаётся третьим сторонам.

## Факты и авторские сведения

`site-data.js` хранит ID/категории/цены в евроцентах и ISO-коды стран. Названия и страны берутся из словаря, EUR форматируется через Intl (`ru-RU` / `en-IE`) без конвертации. Поиск использует названия текущего языка. Категория сохраняется при переключении; поисковый текст сохраняется, поэтому после перевода он может дать пустую выдачу.

Авторство, оригинальные названия фото, URL и названия лицензий берутся из **единственного неизменённого** `assets/products/sources.json`. В словари входят только пользовательские подписи и описание обработки. У музейного кредита часть в скобках — пояснение, а не имя автора: отображаемое имя сохраняется, пояснение переводится отдельно (`sourceNotes`). Лицензия CC BY-SA 4.0 и её ссылка не переводятся/не заменяются; описанное действие над фото не менялось. Асинхронная готовность атрибуции доступна тестам как `window.omniaReady`.

## Проверка перед PR

Запустить три браузерных набора из README. Добавить новые ключи в оба словаря, проверить отсутствие пропусков/смешанных фраз, числовые факты, прямые языковые URL, переходы/reload, отказ хранилища, клавиатуру, узкие экраны и длинные переводы. Сохранить RU/EN скриншоты. Нельзя менять регламент или финансовые правила ради сокращения перевода.

Ограничение текущего статического этапа: без JavaScript доступен русский fallback текста How It Works и обычные ссылки; переключение языка и каталог требуют JS. Локальный HTTP нужен для манифеста; `file://` не поддерживается. Другие языки, страницы и backend — отдельные согласованные задачи.

## Третья страница: Earn with Omnia-Mundi (Issue #10)

`earn-with-omnia-mundi.html` подключает тот же порядок site-data → RU/EN → i18n → navigation; собственного JS или второго переключателя нет. Добавлены только ключи `earn.*`, например `earn.procurer.reward` и `earn.fields.requirements`. Русский fallback размечен этими ключами; title/description/ARIA также локализуются. Общая шапка, footer и диалог переиспользованы.

В `site-data.js` существующей записи `id:"earn"` добавлен `href:"earn-with-omnia-mundi.html"`. navigation.js сам создаёт ссылку и текущий aria-current; OmniaI18n сохраняет язык и целевые query/hash. Ссылка на объяснение финансов ведёт на `how-it-works.html#income`. Остальные будущие разделы не менялись. Сценарии всех трёх страниц проверяет tests/earn.py, включая отказ storage и русский fallback без JS.
