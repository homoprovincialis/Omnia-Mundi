## Запуск

```sh
python3 -m http.server 3010 --bind 127.0.0.1
# Другой терминал:
python3 tests/homepage.py
python3 tests/how_it_works.py
```

Локальное открытие: `http://localhost:3010/how-it-works.html` или ссылка в футере главной. Это локальная разработка, сайт не опубликован. Для запуска сайта runtime-зависимости и секреты не нужны; для тестов используются установленные Playwright и Chromium.
