# Этап 1: только статическая главная страница

Задача #2 и Omnia-Mundi_Codex_Homepage_Phase_1_RU.txt имеют приоритет над более широким объёмом §06.1 и этапом 1 основного регламента. Прочитаны полностью оба TXT из main, включая 29 разделов и T01–T35. Реализуется одна русскоязычная главная: компактная шапка, меню, демокаталог и нижняя навигация. Финансы, API, база, личные кабинеты, авторизация и реальные покупки не входят в этот этап. Старый код PR #1 не используется. Утверждённый SVG не изменяется. Фото требуют подтверждённых источников и лицензий; до их получения этап не считается завершённым.


Владелец одобрил Wikimedia Commons вместо Unsplash в комментариях PR #3. Добавлены локальные миниатюры и компактный раскрываемый блок источников для соблюдения атрибуции. Один сомнительный кандидат наушников заменён другим снимком Commons с явным PD-self; детали в ASSETS.md. Это не расширение функционального этапа.
