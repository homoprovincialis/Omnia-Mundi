# PR #14 — уточнение финансовых текстов

Последнее решение владельца в PR #14 имеет приоритет над прежними примерами и предложениями документов: на How It Works и Earn нет произвольных денежных сумм; таблицы содержат только 20/20/5/5/10/20/20 = 100% P. Moderator — 5+5+10 внутри общей доли 20%, а не дополнительная доля. Более раннее описание Moderator одной общей ролью в оригинальном DOCX не отменяет утверждённые специализации TXT.

SSC оплачивает покупатель как отдельно показанную часть конечной цены товара; расчёт индивидуален для магазина, учитывает расходы, количество товаров и другие факторы, может меняться ежедневно. Единой месячной формулы и ставки нет. SSC — возмещение затрат до P, не прибыль; доля Store Receiver 20% P отдельна. Оригинальный DOCX не изменён.

Проверки сохраняют побайтовый эталон именно утверждённых входных файлов PR на коммите `04e6ab7d95ca8e2b6aa1e26f467df8ddb188197b`; остальные защищённые файлы по-прежнему сравниваются с `origin/main`. Денежные примеры не восстанавливаются ради тестов.

Последнее уточнение владельца требует ровно один новый full-page снимок Earn RU, 1440 CSS px, и краткий отчёт в комментарии PR. Старые одобренные снимки сохраняются; временные результаты регрессионных скриптов не включаются в PR.
