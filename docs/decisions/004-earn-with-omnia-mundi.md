# Issue #10 — Earn with Omnia-Mundi

Ветка `feat/earn-with-omnia-mundi` создана от актуальной main `fa1bc9ff3cfa2ecbaab92976cb8f777fdbd9ac4e` после принятого PR #9. Issue прочитан полностью. Главный регламент и Roadmap побайтно не изменились относительно уже полностью прочитанных источников; порядок страниц соблюдён: только Earn, не Receiver Network и не Stores. Прочитаны текущие AGENTS.md/docs/i18n.md и принятые реализации.

Создана одна статическая информационная страница RU/EN на существующем OmniaI18n. Все прежние ключи переводов сохраняются; добавлен namespace earn.*. В site-data изменена только запись earn: добавлен href. i18n.js/navigation.js, HTML/JS двух существующих страниц, фото/SVG/атрибуция и регламенты не меняются. Использован существующий текстовый layout `.how-it-works` с дополнительным классом `.earn-page`; единственное scoped CSS-добавление оформляет один CTA, который показывает прежний диалог о разработке.

Для ровно пяти основных ролей — Procurer, Manufacturer, Seller, Receiver, Moderator — даны пять компактных полей: функция, проверки, возможности, вознаграждение, будущая заявка. Customer и совмещение ролей объяснены отдельно. Нет живых форм, регистраций, обещаний доходности, новых сроков/депозитов/комиссий. Требования по подтверждениям, обучению и допускам описаны как будущий путь, не как уже присвоенный статус.

Учебный пример относится к положительной P, не к конечной цене. Источник — только один из трёх отправительских типов; 20/20/5/5/10/20/20 =100% P. Раннее возмещение Procurer отделено от поздней прибыли. Цена передачи Manufacturer/Seller не объявлена себестоимостью. SSC — расход, депозит — возвратное обеспечение, Protection Fund — отдельный резерв. Специальные консигнационные условия/сроки и вознаграждение Moderator вне сделки не придуманы. Подробное объяснение не дублируется целиком: дана ссылка на принятую How It Works.

Скриншоты — только прямые full-page PNG локально запущенной страницы в настоящем Chromium через Playwright. Не используются stock/generated/mockup изображения. Для воспроизводимости сохранены URL, размер окна, версия браузера, SHA-256 PNG и отрисованного HTML в captures.json; результаты команд с exit code и stdout — в docs/test-results/issue-10/. Приватность, main, auto-merge и deployment не меняются.
