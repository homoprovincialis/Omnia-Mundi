## Реализация

Один `i18n.js` и два одинаковых по ключам словаря: **148 ключей RU и EN**. Покрыты статические и динамические тексты обеих страниц: шапка/меню/футер, категории/страны/товары/alt, поиск/пустая выдача/статус, атрибуция, диалоги, How It Works целиком, title/meta/ARIA. Русский fallback сохранён в разметке; несовместимый старый strings.ru.js удалён. Товарные факты отделены в site-data.js, авторские данные читаются из единственного локального неизменённого sources.json.

Язык выбирается явными RU/EN, URL → storage → RU; ошибки чтения и записи storage перехватываются. HTML-ссылки сохраняют язык, смена сохраняет якорь и прочие параметры. Выбранная категория/строка поиска не сбрасываются. EUR форматируется по локали без конвертации и изменения целых центов. Авторы, оригинальные названия и названия лицензий/ссылки не переводятся. Музейное пояснение и описание обработки переведены отдельно, без изменения исходного манифеста.

## Ограничения

Рабочий переключатель и каталог требуют JavaScript и локального HTTP; без JS остаются русская fallback-информация How It Works и обычные ссылки. Английский перевод подготовлен по утверждённому русскому содержимому, но не объявляется юридическим переводом для реальной торговли. Владелец утверждает итоговые формулировки и расположение переключателя по скриншотам. Следующие страницы используют этот механизм по docs/i18n.md и AGENTS.md, но сейчас не реализуются.
