# Omnia-Mundi — утверждённый дизайн главной страницы (25 октября 2026)

**Статус:** дизайн выбран владельцем проекта. Это самостоятельное задание на ПЕРЕДЕЛКУ ВНЕШНЕГО ВИДА действующего локального прототипа, а не разрешение придумывать новую торговую модель.

## Основной принцип
Воспроизвести согласованный третий — «сбалансированный» — вариант макета из обсуждения 25.10.2026, с последним уточнением: **ровно четыре небольшие фотографии товаров в ряд на компьютере, каждая ровно 118 × 118 CSS px**. Основное пространство отводится каталогу товаров. Весь старый маркетинговый UI первой версии (большой hero с надписями, декоративный глобус, плавающие карточки, баннерные секции, слоганы) нужно убрать полностью: владельцу не нравится старый сайт, его дизайн не является образцом.

## Обязательный официальный логотип
- **Использовать ТОЧНО утверждённый файл** `public/assets/omnia-mundi-logo.svg` (в этом PR). Это зафиксированное векторное изображение, скопированное без переработки из утверждённого `Omnia-Mundi_logo_black_white.svg`.
- Вид: только `OMNIA-MUNDI` чёрным `#000000` на белом `#FFFFFF`. Шрифт-источник: Lato Black, вес 900. Текст в SVG переведён в векторные контуры, что исключает замену шрифта браузером.
- Никаких полосок, иконок, градиентов, слоганов, эмблем или других надписей рядом с логотипом. Сохранять белый фон и все поля исходного файла; не кадрировать, не растягивать непропорционально.
- В шапке на десктопе показывать его шириной ~160 CSS px, с пропорциональной высотой. Размер на других экранах только пропорционально уменьшать по необходимости.
- Исходная техническая спецификация логотипа отдельно существует у владельца: `Omnia-Mundi_Logo_Specifications_RU.txt`; не создавать ему новую «альтернативную» версию.

## Компоновка десктопа — буквальная реконструкция утверждённого макета
1. **Белая шапка** по ширине контейнера: слева официальный логотип; справа от него длинная горизонтальная строка поиска товаров с иконкой лупы; справа две простые иконки «Войти» (человек) и «Корзина». Шапка спокойная и компактная, без высокой заставки.
2. Тонкий светло-серый разделитель.
3. **Одна горизонтальная строка навигации**: «Каталог», «Производители», «Бесплатные товары», «Запросы». Справа отдельная текстовая ссылка с маленьким знаком плюс «Найти отсутствующий товар» (акцентный синий). Никаких рекламных текстов.
4. Тонкий светло-серый разделитель.
5. **Две колонки основного содержания**: узкая левая панель фильтров (~116 CSS px) и каталог справа; отступ между колонками ~12–16 px.
6. **Левая панель** без цветной подложки и без крупных плиток: заголовок «Категории», затем простые вертикальные ссылки «Все товары», «Электроника», «Для дома», «Одежда», «Аксессуары», «Инструменты», «Другое»; тонкий разделитель; «Страна» → «Все страны»; разделитель; «Цена» → «EUR (€)». Это элементы макета. Реальные фильтры должны опираться на данные приложения; не создавать несуществующее поведение.
7. **Каталог справа**: компактный заголовок «Каталог товаров»; справа маленькая кнопка/значок «Фильтры». Без дополнительного широкого декоративного блока.
8. Под заголовком **сетка из 4 столбцов на десктопе**, выровненная по левому краю области каталога, между карточками ~8–12 px. Главное: фотография строго квадратная 118 × 118 CSS px и **НЕ растягивается при расширении браузера**. Не использовать `width:100%` для фотографии на большой карточке, не делать гигантские карточки, не подменять фотографии геометрическими символами или декоративными иллюстрациями.
9. В каждой карточке без тяжёлой рамки, ниже фото: небольшое чёрное название товара; затем цена в EUR (`€39,00`); ниже маленьким серым текстом страна. Простые вертикальные отступы ~4 px. Левое выравнивание. Карточки в две и более строки. На исходном примере были: наушники, чашка, кошелёк, лампа / сумка, термос, шуруповёрт, часы. **Эти позиции и цены лишь визуальные примеры, не настоящие предложения**; живые карточки должны показывать данные из текущего каталога и реальную страну, не сочинять товарные предложения.
10. Занимать ширину браузера рационально, но не увеличивать карточки ради заполнения пространства. Справа на широких мониторах допустимо свободное белое пространство — приоритет ровно 4 столбца и фотографии 118 × 118 px, как утверждено.

## Стиль
- Фон `#FFFFFF`; основной текст `#000000`; второстепенный текст — спокойный серый (приблизительно `#6B7280`); разделители — очень светло-серые (приблизительно `#E5E7EB`).
- Один ненавязчивый синий акцент для ссылок, например `#2463CC`; логотип остаётся строго чёрным.
- Простой современный шрифт без декоративности, умеренные размеры, минимум рамок/теней, плотная удобная композиция.
- **Запрещены**: баннеры, рекламные карусели, промосекции, hero-иллюстрации, глобусы и абстрактные фигуры, огромные заголовки, лозунги/мото/пафосные цитаты, фальшивые скидки, выдуманные рейтинги.
- Изображения товаров — настоящие предметные фото, насколько позволяют доступные законные данные. Если есть только демо-каталог, чётко обозначить его как демо, не выдавать иллюстративные предложения за реальные. Не затягивать сторонние изображения без права использования.

## Адаптивность и практическая функциональность
- На компьютере: 4 столбца, фото 118 × 118 px. На узких телефонах: 2 столбца, компактная мобильная шапка, фильтры в доступной сворачиваемой панели. **Горизонтальной прокрутки всей страницы не должно быть**. Масштаб карточек на мобильном не должен становиться гигантским.
- Реально работающие поиск, каталог и существующие действия должны сохраниться; никаких кнопок-пустышек. Не придумывать отсутствующую бизнес-логику для ссылок/ролей и не включать незавершённые коммерческие процессы.
- Сейчас только демонстрационный локальный сайт. Запрещено запускать реальные платежи, логистику и публичный деплой.
- Переписать/удалить старую визуальную часть по необходимости, но **не удалять полезный проверенный backend/API/финансовые тесты ради замены дизайна** без отдельного задания.

## Проверка соответствия перед сдачей
- Главная страница сразу показывает товары: нет большого hero/баннера/лозунгов.
- Логотип точь-в-точь `public/assets/omnia-mundi-logo.svg`, без изменений.
- Две строки шапки/навигации, слева фильтры, справа каталог.
- Десктоп: 4 фото в строке **ровно 118 × 118 px**; 2 на мобильном.
- Чёрный текст на белом фоне, минимум декора.
- Нет фиктивных торговых заявлений.
- Сохранены рабочие API, поиск и тесты; отдельно указать, что не сделано.
- Приложить скриншоты десктопа (например, 1440 px) и телефона (например, 390 px), чтобы владелец мог визуально проверить до принятия.
- **Не сливать в main** и не публиковать сайт. Оставить изменения в отдельной ветке и Draft PR. Владелец лично принимает решение о слиянии.

## Границы задачи

Не считать текущие предположения кода юридически/экономически утверждёнными. Если для изменения UI необходимо выбрать новое бизнес-правило или изменить утверждённую концепцию, **остановиться и задать вопрос**, не изобретать решения.
