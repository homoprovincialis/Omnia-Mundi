## Фотографии демотоваров — проверка прав не завершена

Владелец выбрал Unsplash. После обновления настроек 25 октября 2026 года `images.unsplash.com` отвечает HTTP 200. Восемь JPEG скачаны и визуально проверены только во временном каталоге `/tmp/omnia-photo-candidates`; в Git они не добавлены.

Страница https://unsplash.com/license и страницы фотографий возвращают HTTP 401 с заголовком «Making sure you're not a bot!». Проверка обычным HTTP-клиентом не дала доступа к лицензии или авторским сведениям. Unsplash Dataset не использован: его отдельные условия нельзя подменять лицензией фотографий. Не удалось подтвердить лицензию и автора каждого файла; эти снимки не разрешены к включению в PR на основании одного лишь работающего CDN.
